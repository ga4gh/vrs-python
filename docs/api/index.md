# API reference

Install `ga4gh.vrs[extras]` for translation, HGVS utilities, and VCF annotation.

- [GKM-Core models](core-models.md): Create and validate GKM-Core objects.
- [VRS models](vrs-models.md): Create and validate VRS objects.
- [Identifiers and digests](identifiers-and-digests.md): Compute identifiers and digests for VRS objects.
- [Normalization](normalization.md): Normalize equivalent allele descriptions to a consistent representation.
- [Data proxies](data-proxies.md): Retrieve sequences, translate aliases, and validate sequence data.
- [Translation and HGVS](translation-and-hgvs.md): Convert variant descriptions to and from VRS.
- [Object references and storage](object-references-and-storage.md): Replace nested objects with references, resolve references, and store objects.
- [VCF annotation](vcf-annotation.md): Annotate VCF records with VRS allele identifiers from Python.
- [VRS annotate](../extras/vrs-annotate.md): Annotate VCF files with VRS allele identifiers from the command line.
