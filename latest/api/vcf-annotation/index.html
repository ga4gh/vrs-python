VCF annotation

Annotate VCFs with VRS identifiers and attributes.

The main processing path is::

annotate(...)
+ for each record: _get_vrs_data(...)
  + for each allele: _get_vrs_object(...)
    + AlleleTranslator.from_gnomad(...)
    + on_vrs_object(...)             # return an allele or None
+ on_vrs_object_collection(...)       # when collection is enabled

For example, keep only alleles with literal states::

from pathlib import Path
from ga4gh.vrs.extras.annotator.vcf import VcfAnnotator
from ga4gh.vrs.models import Allele, LiteralSequenceExpression


class LiteralStateAnnotator(VcfAnnotator):
    def on_vrs_object(
        self, vcf_coords: str, vrs_allele: Allele, **kwargs: object
    ) -> Allele | None:
        if isinstance(vrs_allele.state, LiteralSequenceExpression):
            return vrs_allele
        return None


# data_proxy must serve the input VCF's reference assembly.
LiteralStateAnnotator(data_proxy).annotate(
    Path("input.vcf"), output_ndjson_path=Path("literal-alleles.ndjson")
)

A pickle or NDJSON output enables VcfAnnotator's collection hook. Returning None excludes the allele from collection. If writing a VCF, its record remains with missing annotation values. Per-record errors are logged and written to VRS_Error.

AbstractVcfAnnotator 

AbstractVcfAnnotator(
    data_proxy: _DataProxy, **kwargs: object
)

Bases: ABC

Abstract class for VCF annotation with VRS.

Child classes must implement all abstract methods, though some may be less relevant and can just be stubbed out (for example, if the desired side effect for each VRS object is something like a REST request, there may be no need for extra cleanup in on_vrs_object_collection).

Critically, implementations that intend to do something with all VRS objects at once following ingestion (e.g. writing a PKL dump) need to set the class variable collect_alleles to True.

VcfAnnotator 

VcfAnnotator(data_proxy: _DataProxy, **kwargs: object)

Bases: AbstractVcfAnnotator

Annotate VCFs with VRS allele IDs.

Uses pysam to ingest a VCF and produce a copy annotated with VRS IDs (and, optionally, normalized allele attributes). Alleles are translated using the VRS-Python translator class.
