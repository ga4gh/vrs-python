Data proxy interface

The data proxy interface defines sequence retrieval, alias translation, and validation.

Bases: ABC

abstract class / interface for VRS data needs

The proxy MUST support the use of GA4GH sequence identifers (i.e., ga4gh:SQ...) as keys, and return these identifiers among the aliases for a sequence. These identifiers may be supported natively by the data source or synthesized by the proxy from the data source or synthesized.

validate_location_bounds 

validate_location_bounds(
    sequence_id: str,
    start_pos: int | Range | None,
    end_pos: int | Range | None,
) -> None

Ensure that start_pos and end_pos are representable on sequence_id.

Each defined coordinate must be within [0, len(sequence)] (inter-residue). Undefined (None) endpoints are skipped, and for a Range every defined member is checked.

start_pos must also not be after end_pos, comparing a Range by its lowest possible start and highest possible end.

There is no require_validation option: an out-of-bounds location has no meaning, so the error is always raised, including from validate_ref_seq. Sequence backends may silently truncate out-of-range fetches, so this check must be made before relying on fetched sequence.
